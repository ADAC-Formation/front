# ADAC Training Platform — Frontend

Frontend application for the training platform developed for the **ADAC association**.

This repository contains the frontend of the platform. The backend is maintained in a separate repository within the ADAC organization.

## 🚀 Tech Stack

* React
* Vite
* JavaScript
* React Router
* CSS Modules
* Lucide React

## 📁 Project Structure

The frontend follows an **Atomic Design** approach, with reusable components organized into:

* `atoms`
* `molecules`
* `organisms`
* `pages`
* `layouts`

## 🛠️ Development

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

## 🔐 Configuration

Environment variables and credentials must not be committed to the repository.

Local environment-specific configuration should be stored in `.env` files and excluded from version control.
